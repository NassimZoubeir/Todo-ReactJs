# Todo List – React + TypeScript

Application de gestion de tâches développée avec **React**, **TypeScript** et **Vite**.

## Fonctionnalités

* Ajouter une tâche
* Supprimer une tâche
* Modifier une tâche
* Définir une priorité : Urgente, Moyenne ou Basse
* Marquer une tâche comme terminée
* Sauvegarder les tâches dans le `localStorage`

## Technologies utilisées

* React
* TypeScript
* Vite
* CSS
* LocalStorage

## Installation

Cloner le projet :

```bash
git clone <URL_DU_REPOSITORY>
```

Installer les dépendances :

```bash
npm install
```

Lancer le projet :

```bash
npm run dev
```

L'application sera ensuite accessible à l'adresse indiquée par Vite dans le terminal.

## Objectif

Projet réalisé afin de pratiquer React et TypeScript, notamment les `useState`, `useEffect`, la gestion des composants et la persistance des données avec `localStorage`.
